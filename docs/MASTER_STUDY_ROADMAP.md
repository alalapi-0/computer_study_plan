# 总练习路线

> 2026-10-13 · 问题优先；阶段依赖见ROADMAP，实时验收见PROJECT_STATE。

先选择一个能描述症状的小问题，在一次性环境亲自修复，再扩大问题覆盖。首批代表方向：文件/权限 → 小脚本/Git → 持久化/重复请求 → API契约子集 → 产物质量。标签可以跨方向，不创建新的完整课程。

基础路径题是最小闭环基准；权限题练习保留最小访问范围；Git题保留未提交工作；持久化与重试题从重启和重复调用后的真实数据检查；媒体题从WAV结构和音频参数检查。具体症状/命令/预期以各versioned scenario.json为准，不复制正文。

后续两节点网络、系统VM、真实前端/后台任务、AI接口和其他OS按实际运行能力独立加入，不能用资料阅读或模拟输出充当实操。

原课程 `linux-foundations`、Round00/01/02/06与VPS材料保留在历史入口和原路径，80任务的完成记录仍是课程完成记录。远程VPS写操作需要明确授权。旧课程路线不再充当当前产品调度队列。
