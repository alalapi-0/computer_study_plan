# Product Vision · 真实问题驱动

> 2026-10-13 · 根据用户当前重构请求更新；唯一当前状态见PROJECT_STATE。

组织单位是一个实际问题：环境、症状、目标、约束、可持续阅读的提示、解答、结果检查和复练。用户亲自观察现场、查资料、形成判断、修改并检查结果。开发Agent可以验工程，但不能冒充用户学习或独立解题。

Linux是首版运行环境，不是知识边界。用少量问题覆盖多条工程方向；每题围绕一条主要因果链，不再铺设大而全课程。原 `linux-foundations` 保留为历史课程，既有Round和记录不丢弃，也不新增其他正式课程。

主流程：选问题 → 建立可丢弃实验 → 观察/调查 → 修改 → 管理侧独立检查目标和保护约束 → 阅读反馈/证据 → 重置复练。不同合法方法可以达到相同目标。终端退出0、HTTP200、点击完成、输出特定词均不能单独证明修复。

提示常开时完整步骤持续可读；常关时等待、失败或检查不会自动剧透。偏好跨刷新、新题保持，切换不改变环境。解答独立显式入口，无需先通关。允许man/help、查资料和主动寻求AI帮助。固定已发布内容、执行和检查不依赖在线AI。

Attempt区分开始、环境存活、提示/解答使用、判定、证据和结束；辅助阅读不等于失败，检查通过不等于独立掌握。旧done语义不变。无依据的XP、Mastery、成就、复习日期不出现在新界面。

首版技术成功要求至少一道题从真实故障到解决再重置可重复，以及本机支持的代表题全部通过发布门禁。持续学习、独立操作、趣味性和产品接受需要用户实练，不能由代验推断。原生macOS/Windows、完整系统VM、硬件题与双节点网络须分别实装并验收；不可使用换Shell或编造输出代替。
